# FLEET COMMAND / 魚雷ゲーム

9×9の海域を舞台に、艦隊編成と多彩な兵装・レーダー索敵を駆使してCPU艦隊と戦うターン制のコンソール（ASCII）魚雷ゲームです。

## ゲームの概要

プレイヤーは6種類の艦種から2〜3隻を選んで自艦隊を編成し、9×9の海域に配置します。魚雷や爆雷による攻撃と、レーダーによる索敵を組み合わせて敵艦隊の位置を特定し、敵艦をすべて撃沈（または攻撃不能に）することが目的です。

## 動作環境

- OS：Windows 11 / macOS
- Python：Python 3.10以降
- 必要なライブラリ：追加ライブラリ不要（Python標準ライブラリのみ使用）

## インストール方法

Python 3 がインストールされている環境であれば、追加のライブラリ導入は不要です。リポジトリをクローンまたはファイルをダウンロードしてそのまま実行できます。

## 起動方法

プロジェクトフォルダー直下で以下のコマンドを実行します。

```bash
python torpedo_game.py
```

### コマンドラインオプション（任意）

```bash
python torpedo_game.py --hard             # CPUをハードモードで開始
python torpedo_game.py --no-animations    # ASCIIアート演出の待ち時間を省略
python torpedo_game.py --demo             # 自動対戦で動作確認を実行
python torpedo_game.py --debug 5          # 検証モード（4, 5, 6から海域サイズを指定）
python torpedo_game.py --seed 42          # 乱数シードを固定して実行
```

## 操作方法

- 難易度選択：`n`（通常）または `h`（難しい）を入力（Enterのみで通常）
- 艦隊編成：1〜6の番号を空白区切りで2〜3隻入力（例：`1 4 6`、同じ艦種の重複可）
- 艦隊配置：`a`（自動配置）または `m`（手動配置：左上座標と90度回転 `y/N` を指定）
- 兵装選択：画面に表示された兵装の番号を入力
- 目標座標：`列 行` を空白区切りで入力（例：`3 5`、1〜9の範囲）
- 方向レーダーの向き：`w`（上）/ `a`（左）/ `s`（下）/ `d`（右）
- ゲーム終了：入力プロンプトで `q` を入力（または `Ctrl + C`）

### ルールと盤面表示

- **勝利条件**：敵艦隊のすべての艦を撃沈する、または攻撃手段を持つ敵艦をすべて撃沈する。
- **敗北条件**：自艦隊が全滅する、または攻撃手段を持つ艦をすべて失う（支援艦のみの編成は開始時に敗北）。
- **盤面の記号**：`X` 命中 / `o` 外れ / `?` 至近弾（周囲8マス以内に艦影あり） / `^` 艦影反応 / `-` 反応なし / `.` 未調査

## 追加・改良した機能

### 改良機能01：艦隊編成と多彩な兵装・レーダー索敵システム

攻撃型潜水艦・通常型潜水艦・原子力潜水艦・駆逐艦・空母・偵察機の6艦種から2〜3隻を自由に編成できるようにしました。通常魚雷・二連装魚雷・十字魚雷・爆雷（3×3）の攻撃兵装に加え、通常レーダー（3×3）・広域レーダー（5×5）・方向レーダー（直線5マス）による索敵を実装しています。レーダーの探知結果（`^` / `-`）は2行動分だけ敵海域に一時表示されます。

### 改良機能02：2段階のCPU難易度（通常／ハードモード）

命中や至近弾の周囲を探索する通常CPUに加え、ハードモードを実装しました。ハードモードでは市松模様（チェッカーパターン）で効率的に索敵を行い、連続して命中した場合は艦の向きを推測して直線上に追尾攻撃を行います。

### 改良機能03：ASCIIアート演出とデバッグ・デモ用オプション

艦隊出撃時および撃沈時にASCIIアートによる演出を表示します。また、動作確認やバランス検証を容易にするため、`--debug`（縮小海域・敵配置公開・反撃なし）、`--demo`（自動対戦）、`--seed`（乱数固定）、`--no-animations`（演出省略）のコマンドラインオプションを実装しました。
